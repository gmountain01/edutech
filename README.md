# edutech — 교사용 AI 시리즈 3권(AI 에듀테크) 진행 현황

선생님들이 시장조사를 근거로 툴을 고르고 가목차를 짜 오시도록 돕는 회의·과제 페이지입니다.

- 사이트: https://gmountain01.github.io/edutech/
- `index.html` — 페이지 원본(데이터는 `/*DATA*/` 구간에 빌드로 채움)
- `docs/index.html` — GitHub Pages 용 완성본(빌드가 만듦)
- `build_site.py` — 툴 37종·참고 도서 89권 데이터를 만들어 두 파일에 넣음. 원본 엑셀·목차 캐시는 저장소 밖(`../00_자료조사`, `../00_기획서`)에 있어 이 저장소만으로는 다시 빌드할 수 없음
- `03_선생님작업/3권_가목차과제_양식.xlsx` — 선생님 작업 시트 양식(툴 선별 · 가목차 · 추가 제안)
- `01_자료조사/toc_extra.jsonl` — 신간 5권 예스24 목차 추가 수집본
